# Hearthside brand

Logo: monoline house with three rising bars and a chimney with a curl of smoke.

| File | Use |
| --- | --- |
| `logo.svg`, `logo-1024.png` | Master logo (app header, marketing) |
| `favicon.svg`, `favicon.ico`, `favicon-16/32/48.png` | Browser tab. A simplified version with thicker strokes and no chimney so it stays readable at 16 px |
| `apple-touch-icon.png` (180) | iOS home screen |
| `icon-192.png`, `icon-512.png` | Web app manifest icons |
